# Hirelance 🎓💼

Hirelance es una **aplicación móvil (Android)** diseñada para conectar a estudiantes universitarios y técnicos en El Salvador con clientes y empresas que necesitan servicios técnicos, creativos y profesionales.
## 🎯 El Problema

[cite_start]Los estudiantes en El Salvador a menudo tienen dificultades para encontrar experiencia laboral relevante o generar ingresos en sus campos de estudio[cite: 17]. [cite_start]Paralelamente, muchas pequeñas empresas y emprendedores necesitan servicios técnicos (diseño web, mantenimiento, tutorías) pero no cuentan con una vía confiable para contratar jóvenes talentosos a precios accesibles[cite: 17].
## 💡 La Solución

[cite_start]Hirelance busca ser el puente digital que conecte ambos mundos[cite: 15]. Es una **aplicación nativa de Android** donde:

* [cite_start]**Los Estudiantes** pueden crear perfiles profesionales, mostrar su portafolio, habilidades y formación académica[cite: 20].
* [cite_start]**Los Clientes** pueden publicar proyectos o buscar directamente perfiles de estudiantes filtrando por especialidad, universidad o ubicación[cite: 21].

## ✨ Características Principales

* [cite_start]**Perfiles de Estudiante:** Registro detallado con universidad, carrera, habilidades, portafolio y tarifas[cite: 20, 41].
* [cite_start]**Búsqueda Avanzada:** Filtros por especialidad, institución y geolocalización[cite: 42, 44].
* [cite_start]**Sistema de Reseñas:** Valoraciones bidireccionales (estudiante-cliente) para generar confianza[cite: 43, 53].
* [cite_start]**Chat Integrado:** Un sistema de mensajería para facilitar la comunicación y negociación[cite: 22, 45].
* [cite_start]**Notificaciones Push:** Alertas de mensajes, proyectos o valoraciones recibidas.
